# EQ Mirror

The landing page for EQ Mirror, an analyser that shows what a third party EQ
is actually doing to a signal.

Nothing is here yet. The name is what is being kept.

GitHub Pages serves a project site at `<owner>.github.io/<repo>/`, and GitHub
does not redirect that path when a repository is renamed -- repository URLs,
clones and releases are redirected, but the Pages path is not. The page, the
EULA, the trial download, the store listing and anything that has been indexed
would all move with it. So the name is taken now and left alone.

Private until the page is ready, then public.

The plugin's own source is private and lives elsewhere.
